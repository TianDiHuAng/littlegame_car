# 《亮车计划》上线检查清单

> 依据微信开放文档「小游戏接入指南」整理（文档最后编辑 2026-07）。
> 平台规则会变，正式提交前请以 [官方文档](https://developers.weixin.qq.com/minigame/introduction/guide/) 为准。

---

## 一、先选路线：IAA 还是 IAP

| | IAA（推荐） | IAP |
|---|---|---|
| 变现 | 广告 | 虚拟支付（内购） |
| 备案路径 | **情况二：当前及未来均不需要开通虚拟支付** | 情况一 |
| 资质 | 一般只需备案材料 | 需要版号等更重的资质 |
| 个人主体 | 可以 | 受限 |

**这个游戏走 IAA。** 本来也没打算做内购。

> ⚠️ 选了「情况二」意味着**以后都不能开通虚拟支付**。如果将来想加内购，需要重新走一套。
> 反过来说，个人主体也只能走这条。

---

## 二、时间线（这是最关键的认知）

```
第 0 天    注册小游戏账号 + 认证
第 0 天    提交「资质审核(IAA)」         ← 1–3 个自然日
第 0 天    提交「小游戏备案」            ← 平台初审 1–2 工作日
                                        + 主管部门 10–20 工作日  ★ 最大瓶颈
第 X 天    小游戏备案通过 → 提交「小程序备案（工信）」
                                        ← 含短信核验、通管局审核
第 X 天    上传代码 → 提交「版本审核」    ← 1 个自然日
第 X 天    版本审核通过 + 小程序备案完成 → 才能点「发布」
```

**所以：备案要尽早启动，不要等游戏做完。**
从零到能发布，最快也要 **2–4 周**，主要卡在主管部门那 10–20 个工作日。

## 三、逐项待办

### 1. 注册与认证

- [ ] 去 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册，类型选**小游戏**
- [ ] 主体：个人 或 企业（个人也能上 IAA 游戏）
- [ ] 微信认证（企业需要；个人主体规则以页面为准）

### 2. 名称 / 简介 / 头像

- [ ] 名称：**「亮车计划」**——纯中文，不含英文和「软件」字样
- [ ] 名称必须**唯一**：与已获批的游戏重名会被驳回
- [ ] 名称要和玩法有关联（不能叫和内容无关的名字）
- [ ] 头像：建议用分享封面那套视觉

> 💡 名称一旦提交备案，**审核中或通过后就不能改名/改主体**。稳妥起见，查重确认后一次定死。

### 3. 类目设置

- [ ] 类目选 **游戏 → 休闲游戏**（三级类目要选到与玩法一致的那一项）
- [ ] 具体三级类目名以 MP 后台可选项为准

### 4. 资质审核（IAA）

- [ ] MP → 设置 → 游戏设置 → 资质管理 → 前往管理
- [ ] 选择**情况二**：当前及未来均不需要开通虚拟支付
- [ ] 选择不申请支付资质
- [ ] 提交审核（1–3 个自然日）

**什么时候需要额外提交《计算机软件著作权登记证书》？**

1. 游戏名称含英文，或含「软件」字样
2. 涉及品牌、公众人物合作

「亮车计划」两个条件都不占，**大概率不需要软著**。

> 常见驳回：材料与游戏名称/主体不一致、盖章模糊、用连笔签、缺签署日期。

### 5. 小游戏备案

- [ ] 账号设置 → 小程序备案 → 去完善 → 小游戏备案 → 前往提交
- [ ] 填报内容要**清晰完整**：场景、玩法、功能
- [ ] 上传**尺寸和版本一致**的截图（建议直接用 `prototype/screenshot-*.png`）
- [ ] 等待：平台初审 1–2 工作日 + 主管部门 10–20 工作日

**容易被驳回的点：**
- 名称重复
- 备案信息与实际游戏不一致
- 截图尺寸/版本不统一
- 提交后又改名或迁移主体

### 6. 小程序备案（工信）

- [ ] 小游戏备案通过后才会开放入口
- [ ] 五个环节：信息填写 → 平台初审 → 工信部短信核验 → 通管局审核 → 备案成功
- [ ] **短信核验必须及时点**，否则流程会卡住

### 7. 适龄提示

- [ ] 版本审核前必须设置，否则会影响备案时效
- [ ] 这个游戏内容极简单（洗车），选低龄段即可
- [ ] 路径：设置 → 游戏设置 → 适龄提示

### 8. 用户隐私保护指引

- [ ] 提交版本审核时必须完善
- [ ] 本游戏用到的信息：
  - 本地存储（存档）——不上传
  - 微信云存储（`wx.setUserCloudStorage`）——好友排行榜用
  - 关系链（开放数据域读好友数据）
  - 录屏（本地，不上传）
- [ ] 没有账号体系、没有定位、没有通讯录、没有相册

### 9. 中宣部实名认证

- [ ] 文档里有这一环（`中宣部实名认证`）
- [ ] 建议按 MP 后台提示走，休闲游戏通常有简化流程

### 10. 提交版本审核

- [ ] 开发者工具 → 上传（**AppID 要从 `touristappid` 换成真实的**）
- [ ] MP → 版本管理 → 开发版本 → 提交审核
- [ ] 选择游戏引擎（这里是**自研 / 原生 Canvas**，选「小游戏原生」或对应项）
- [ ] 苹果开发者账号为**必填**（可以填邮箱）
- [ ] 填写版本更新说明
- [ ] 宣传图非必填

### 11. 发布

- [ ] 版本审核通过（1 个自然日）
- [ ] **小程序备案也必须完成**，才能点发布

## 五、几个容易踩的坑

| 坑 | 说明 |
|---|---|
| **备案周期长** | 主管部门 10–20 工作日，不要在临发布前才提交 |
| **改名 = 重来** | 备案提交后改名/迁移主体，会退回重走 |
| **重名** | 想好用名，查重确认 |
| **文不对题** | 名称必须和玩法相关，否则驳回 |
| **截图不一致** | 备案截图的尺寸、版本必须统一 |
| **先发后审** | 版本审核通过 ≠ 能发布，还要等工信备案 |
| **情况二不可逆** | 选了 IAA 以后不能开虚拟支付 |

## 六、建议的执行顺序

**今天就能做的：**

1. 注册账号 + 微信认证（1–2 天）
2. 定名称「亮车计划」，查重
3. 选类目、提交 IAA 资质审核（1–3 天）
4. **立刻提交小游戏备案**（10–20 天，这条最长）

**备案在路上时：**

5. 真机测试、修 bug
6. 换真实 AppID，上传代码
7. 准备隐私指引、适龄提示

**备案通过后：**

8. 提交小程序备案（工信）
9. 提交版本审核
10. 两边都通过 → 发布
