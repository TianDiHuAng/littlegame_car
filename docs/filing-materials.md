## 四、玩法说明（填「小游戏内容介绍」用）

> 《亮车计划》是一款休闲解压类小游戏。玩家扮演洗车工，按住屏幕拖动水枪冲洗车辆，把污渍冲干净即可完成订单。
>
> **核心操作**：单指按住并拖动，无需其他按键。
>
> **四种工具，对应四类污渍**：
> - 冲洗：软泥、灰尘、涂鸦
> - 泡沫：厚泥（必须先打泡沫软化才能冲掉）
> - 刮刀：硬垢（水冲不掉，刮开后会露出底下受损的车漆）
> - 补漆：掉漆（用补漆工具修复）
>
> **资源与目标**：每单有水量限制，冲洗会消耗水。水用完还没洗完算失败。结算按剩余水量评 1–3 星，星级越高金币越多。金币可用于升级水压、喷嘴和刮刀头。
>
> **内容规模**：16 个订单，含轿车、面包车、跑车、越野车、货车等 6 种车辆，以及砖墙、陶罐、老窗、轮毂等物件。其中 2 个订单需要连续清洗两辆车，共用一个水箱。
>
> **其他功能**：洗前洗后对比、截图、好友排行榜、禅模式（无限水量，纯解压）。
>
> **无内购、无充值、无抽奖**，仅通过广告变现。

## 九、用户隐私保护指引（要点）

本游戏收集/使用的信息：

| 信息 | 用途 | 是否上传 |
|---|---|---|
| 本地存储 | 保存游戏进度（等级、金币、关卡进度） | 否，仅存本机 |
| 微信云存储（`setUserCloudStorage`） | 好友排行榜的分数 | 是，存于微信侧 |
| 关系链数据（开放数据域） | 展示好友排行榜 | 只读，不落库 |
| 录屏 | 生成分享视频 | 否，仅本地 |

**不收集**：手机号、位置、通讯录、相册、设备标识、支付信息。
**无账号体系**，不要求登录授权。

> 如果后台要求填写「收集用户信息的类型」，按上表勾选即可。

## 十、头像与封面图

在 `docs/brand/`：

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `icon-512.png` | 512×512 | **小程序头像**（注册必填） |
| `icon-144.png` | 144×144 | 小尺寸预览，确认缩到列表里还认得出 |
| `cover-1200x960.jpg` | 1200×960（5:4） | 列表卡片 / 分享卡片 / 宣传图 |

另外游戏内的分享封面是 `minigame/images/share_cover.jpg`（500×400），已经在包里了。

**头像设计**：蓝色天空 + 绿色地面 + 红色小车 + 一道白色水柱和闪光。
刻意只保留大色块，缩到 144px 甚至 64px 仍然能认出「红车在水里」。

**重新生成：**

```bash
# 头像（1024 渲染后缩小）
chrome --headless --window-size=1024,1024 --screenshot=icon.png tools/brand-icon.html

# 封面
chrome --headless --window-size=1200,960 --screenshot=cover.png tools/brand-cover.html
```

> 头像是**满幅方形、不带透明通道**（24 位 RGB）：微信会自己裁成圆角/圆形。\n> 四角没有关键元素，所以裁成圆的也不会切到东西。
