# 微信小游戏 · 解压向概念方案 v0.1

> 目标：轻松、解压、即点即玩。本文只解决"做什么、为什么、先做哪个"，不涉及具体实现。
>
> **注**：本文是立项时的概念方案，其中《冲一冲》就是最终落地的项目，
> 正式名称已定为 **《亮车计划》**。以下保留原始命名以便回溯。

---

## 0. 一句话结论

解压类在微信的胜负手**不是玩法深度**，而是三件事：

1. **3 秒懂**——不读文字就知道手指该干嘛；
2. **手感/ASMR**——每一次操作都有即时的视觉 + 声音回报；
3. **想录屏**——玩家愿意把"好爽的一下"发给朋友。

所以不要一次做 5 个。建议：**一套底座 + 1 个爽感首发 + 1 个收集留存**，用首发测渠道，用留存测长线。

---

## 1. 解压的三根支柱

| 支柱 | 心理机制 | 代表动作 | 微信适配度 |
|---|---|---|---|
| **破坏 / 释放** | 压力外化，即时反馈最强 | 冲洗、戳破、切割、砸 | ★★★★★ 短视频素材天然强 |
| **秩序 / 掌控** | 混乱→整齐的确定性 | 收纳、对齐、分类 | ★★★★★ 女性用户匹配度高 |
| **积累 / 期待** | 低压力下的持续获得 | 钓鱼、收集、养成 | ★★★★☆ 留存最好，但慢热 |

好的解压游戏通常**主支柱 1 个 + 副支柱 1 个**。三根都想要 = 哪个都不爽。

---

## 2. 微信场景约束（先定边界，再谈创意）

| 约束 | 具体要求 | 设计含义 |
|---|---|---|
| 单局时长 | 30–90 秒 | 一个关卡 = 一件事，不要多阶段 |
| 中断 | 随时退出不丢进度 | 自动存档，无"这局白打" |
| 操作 | 竖屏、单手、拇指可达 | 只用一个手指，不需要双手协同 |
| 引导 | 零文字教程 | 第一关用"手指标记 + 一个可点区域"教会 |
| 失败 | 无惩罚或极轻 | 失败 = 重来一次，不扣资源 |
| 首屏 | 3 秒内出画面 | 主包要小，首屏资源预加载 |

## 4. 方案卡片

### A.《冲一冲》— 高压水枪清洁 【推荐首发】

- **一句话**：按住屏幕冲掉污渍，看着一辆脏车变干净。
- **核心循环**：选场景 → 按住拖拽冲洗 → 污渍按遮罩即时消失 → 结算清洁度 → 下一件。
- **操作**：单指按住 + 拖动。水柱跟随手指，松手停水。
- **关卡**：一件"脏东西"= 一关（脏车 / 涂鸦墙 / 雕像 / 油腻灶台 / 泥坑狗）。
- **解压点**：像素级即时消失 + 水声 + 泥浆往下流 + 冲干净瞬间的"唰"和高光。
- **难度设计**：整体好冲，但留 3–5 处"小角落"（缝隙、凹槽）制造"就差一点"，这是复玩动机。
- **内容量**：首发 12 关，之后每周 2 关。
- **开发要点**：污渍 = 程序化噪声生成的遮罩层，擦除用 Canvas 的 `destination-out`，不需要逐张手绘。美术资产可高度复用（同一张车，换颜色/贴纸就是新关）。
- **变现**：新载具/新场景包；激励视频"高压模式 30 秒"。
- **风险与对策**：单场景耐玩度低 → 用"清洁度 100%"的三星评价 + 收集图鉴（洗过的车入库）拉长。

---

### B.《捏一下》— ASMR 触感合集 【最低成本验证】

- **一句话**：一个盒子里装着各种"手痒"玩具：泡泡纸、刮刮乐、削木头、史莱姆、撕胶带。
- **核心循环**：选玩具 → 戳/刮/捏 → 物理反馈 + 音效 → 玩坏了换下一个。
- **操作**：单指点击/滑动。零学习成本。
- **解压点**：纯感官。音效占体验的 60%，必须做"真录音"而不是合成音。
- **内容量**：每个玩具 1–2 人日，首发 5 个。
- **开发要点**：每个玩具是一个独立小模块（接口统一：`enter / update / exit`），方便持续加。
- **变现**：每日一个新玩具（激励视频解锁）；玩具皮肤。
- **风险与对策**：玩具腻了就走 → 用"每日上新 + 收集册"把一次性体验变成打卡。

---

### C.《整整齐齐》— 收纳整理 【长线首选】

- **一句话**：把一个乱糟糟的抽屉/冰箱/行李箱收拾整齐。
- **核心循环**：拖拽物品 → 吸附到虚线框 → 对齐"咔哒" → 全部归位 → 结算完美度。
- **操作**：拖拽 + 轻点旋转（部分物品有正确朝向）。
- **解压点**：吸附的手感、对齐的"咔哒"、完成时的整体闪光。**吸附容差要调大**，宁可太容易也不要"放不进去"。
- **元系统**：完成得金币 → 装修"我的房间"（第二个留存钩子）。
- **内容量**：首发 20 关，主题化更新（厨房 / 化妆台 / 工具箱 / 老屋）。
- **开发要点**：美术是主要成本。用同一套"物品图集 + 九宫格背景"，靠摆放布局出新关。
- **差异化**：同类已有产品，靠**主题叙事**区分——比如"帮奶奶收拾老屋"，每关一件旧物配一句回忆。
- **风险**：美术量大、同质化 → 先做 5 关验证手感，再决定是否铺量。

---

### D.《钓鱼佬的一天》— 放置钓鱼 【留存首选】

- **一句话**：抛竿、等、浮标一沉点一下，收线。
- **核心循环**：抛竿 → 等待（可切后台）→ 浮标下沉 → 点击 → 2 秒拉条小游戏 → 入护。
- **操作**：一次点击 + 一个短拉条。极低操作压力。
- **解压点**：等待的松弛感 + 上钩瞬间的期待 + 图鉴收集。
- **元系统**：60 种鱼图鉴、鱼塘升级、天气/时段影响鱼种、离线收益。
- **开发要点**：重数值、轻美术。数值表（鱼种/概率/重量/价格）是核心资产，先做表再做画面。
- **变现**：离线收益翻倍（激励视频，最自然的广告位）、稀有鱼概率提升。
- **风险与对策**：首日节奏慢 → **第一杆必中大鱼**，前 3 分钟给足正反馈。

---

### E.《一杆入洞》— 极简弹射 【练手 / 跑通发布流程】

- **一句话**：拖拽瞄准，松手弹射，球撞墙反弹进洞。
- **核心循环**：观察 → 拖拽瞄准（显示预测线）→ 松手 → 反弹 → 进洞 / 再来。
- **操作**：单指拖拽 + 松手。无失败，只有步数。
- **解压点**：一击命中的确定快感 + 慢节奏思考。
- **内容量**：100 关 = 100 张矢量小场景，关卡是纯数据（坐标 + 障碍 + 洞位）。
- **开发要点**：物理用简单圆-线段碰撞即可，不需要物理引擎。**最适合先跑通"提审 → 上线 → 看数据"全流程**。
- **变现**：弱。定位是练手和流程验证，不是收入产品。

## 5. 组合策略：一套底座 + N 个玩法

这是把"几个小游戏"变成"可持续"的关键。第一个游戏就把底座做出来，后面每个新游戏只写玩法。

```
shared/                      # 一次做好，所有游戏复用
  ├─ 登录/游客态             # wx.login + 自建账号
  ├─ 云存档                 # 关键进度，防丢
  ├─ 排行榜                 # 好友榜（微信开放数据域）
  ├─ 分享                   # 分享卡片 + 录屏/截屏钩子
  ├─ 广告                   # 激励视频封装（失败重试、预加载）
  ├─ 音频                   # 首次交互解锁、iOS 静音键处理
  ├─ 埋点                   # 关卡漏斗、留存、广告观看率
  └─ 资源加载               # 分包 + 预加载 + 进度条
games/冲一冲/                # 每个游戏 = 玩法壳 + 配置
```

**导量**：同主体的小游戏之间可以用 `wx.navigateToMiniProgram` 互跳（需满足平台关联要求）。A 游戏结算页放 B 游戏的入口，是零成本获客。

**渠道**：同一套代码可同时发微信 / 抖音 / QQ 小游戏。微信验证通过后，迁移成本很低。

## 6. 平台现实（务必核实，不要凭记忆）

| 项 | 说明 | 建议动作 |
|---|---|---|
| 资质 | 个人主体可注册小游戏，但功能受限（一般不能虚拟支付）。游戏类目通常涉及版号/备案要求 | **先按"纯广告变现、无内购"设计**，把资质风险降到最低 |
| ICP 备案 | 小程序/小游戏需完成备案才能上线 | 立项就去办，周期不短 |
| 包体 | 主包约 4MB、总体积 20MB 量级（以官方文档为准） | 引擎裁剪 + 资源图集化 + webp |
| 性能 | 以千元安卓机为基准 | 60fps；粒子 ≤ 200；避免每帧 new 对象 |
| 变现 | 流量主有 UV 门槛（约千级）；激励视频为主力 | 别把收入模型建立在单一 eCPM 假设上 |
| 留存 | 次日留存 30% 可视为健康（经验区间，非承诺） | 首发就看这个数，低于 20% 先修新手引导 |

> 上面带"约/量级"的都是估算，落地前以微信公众平台最新规则为准。

## 7. 验证计划（每个概念 1–3 天，灰盒）

用 `prototype-fast` 的思路：**一次只验证一个问题**。

```
PROTOTYPE BRIEF
QUESTION:   陌生人拿到手，3 秒内会不会自己开始玩？玩完一局会不会主动再来？
CORE VERB:  该方案的核心动词（冲洗 / 戳 / 拖拽归位 / 抛竿 / 弹射）
THROWAWAY?: yes —— 色块 + 一个音效，验证完就删
TIMEBOX:    每个概念 1–3 天
KEEP IF:    3 个没被教过的人里，≥2 人主动再来一局；或有人主动录屏
KILL IF:    需要你解释才玩得下去；或必须加美术才"有点意思"
```

**必须真机测**，别只在开发者工具里跑。灰盒阶段就用真实音效——解压类里音效是玩法的一半。

**测完再决定投不投美术**。解压类最容易犯的错：用漂亮美术掩盖"其实不好玩"。
